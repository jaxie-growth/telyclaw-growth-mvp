生产化说明

  • X API 需要付费档位 + Rate Limit 约束，MVP 用仿真数据跑通链路，src/ingest.js 已实现真实 API 适配层，填 token 即可切换。
  • 生产化数据获取：冷启动期用账号池方案（多账号轮换 + 每账号独立代理 + 限流自动换号，业界参考 twscrape）拿到种子数据，稳态再切官方 API；并用 RSSHub 类聚合源做降级兜底。合规边界见 README 第 4 节。
  • LLM 同理：LLM_MODE=openai 后调用真实模型，Prompt 与校验逻辑不变，失败会自动回退到内置生成器。
  • 审核工作流：作者 / 审核人 / 发布人三角色分离，权限在服务端强制校验（前端按钮禁用只是提示），对齐成熟社媒工具的工作区权限模型。
  • 持久化目前是 data/state.json（便于面试演示复现）；生产环境替换为 Postgres/Supabase，业务模块无需改动。
